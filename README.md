# AI-Novel｜Storyloom

以 **React 18 + Vite 6** 建置的互動小說網站前端原型，使用繁體中文介面。採深色、類 ChatGPT 的工作區配置，支援桌面、平板與手機。

**網站：** https://alice2317.github.io/AI-Novel/

> **目前階段：前端原型與瀏覽器本機資料管理。** 尚未連接 AI 故事引擎、雲端資料庫或登入系統；不要將示範內容視為 AI 即時生成的劇情。

## 技術與啟動

- React 18
- Vite 6
- CSS / RWD
- 瀏覽器 `localStorage`（目前資料保存方式）

需要 Node.js 與 npm：

```bash
npm install
npm run dev
```

其他指令：

```bash
npm run build    # 建置正式版至 dist/
npm run preview  # 預覽正式版
```

## 工作區

### 1. 故事工作台

- 左側「我的故事」清單：新增、切換故事；右鍵故事項目開啟操作選單，可查看故事資訊或確認後刪除故事。
- 頂部故事名稱可點擊開啟故事資訊選單，方便手機使用。
- 右側故事資訊：查看／編輯／儲存故事基本設定，包括名稱、類型、簡介與原作模式。
- 原作模式：無原作（C-1）、啟用原作線（C-2）、只參照原作設定（C-3）。
- 中央上方固定、可收合的故事狀態面板：故事時間、地點、章節、劇情階段。**目前為尚未連動的佔位資料**。
- 故事正文獨立捲動；玩家輸入框固定於中央底部。
- 桌面版左右側欄可收合，分隔線可拖曳調整寬度；手機版使用響應式面板。
- 故事、玩家輸入紀錄保存於目前瀏覽器。

#### 玩家輸入

對話、行動、OS（內心想法）**可寫在同一則訊息中一起送出**，不是互斥的輸入模式：

| 操作 | 效果 |
| --- | --- |
| **對話** | 在游標處插入 `""`，並將游標移到引號中間 |
| **OS** | 如目前不在新行開頭，先插入換行，再插入 `OS `；游標位於空白後 |
| **換行 ↵** | 在游標處插入換行，不送出訊息 |
| 直接輸入文字 | 可描述玩家行動 |
| **Enter** | 送出整則輸入 |
| **Shift + Enter** | 手動換行 |

例如：

```text
"我等等就回來。"
走到門口。
OS 希望他沒有發現。
```

**重要：** OS 應屬玩家私有資訊、不應自動讓 NPC 得知，但目前尚無 AI 引擎實際執行資訊隔離規則。送出只會記錄輸入，不會自動產生新劇情。

### 2. 原作資料庫

分開管理兩種資料：

- **原作資料**：既有作品的參考設定。
- **原創資料**：自行創作的世界與設定。

目前提供：

- 新增、搜尋、選取、編輯及刪除作品／原創世界。
- 資料分類：世界觀、角色資料、人物關係、設定與規則、參考文件。
- 各分類內容可新增、編輯、刪除。
- 資料保存在目前瀏覽器；尚未與故事引擎或故事引用關係串接。

### 3. 備份與結算

- **匯出備份**：下載包含故事、對話紀錄、原作／原創資料庫的 JSON 檔。
- **匯入備份**：讀取本網站匯出的 JSON，經確認後覆蓋目前資料。
- **故事結算**：目前為前端預留畫面，尚未實作正式結局、回合結算或跨卷承接。

### 工作區導航

- 工作區列表預設最多完整顯示三項。
- 可透過設定圖示調整完整顯示的工作區；其他工作區集中在「⋯ 其他」。
- 「我的故事」只會在「故事工作台」工作區顯示。
- 顯示偏好保存在目前瀏覽器。

## 資料儲存與限制

目前資料使用瀏覽器 `localStorage`，**不是雲端同步**：

- 更換裝置／瀏覽器不會自動同步。
- 清除網站資料或使用某些無痕瀏覽情境可能造成資料遺失。
- 請定期透過「備份與結算 → 資料備份」匯出 JSON 備份。
- 匯入會覆蓋現有故事與資料庫，操作前請先備份。
- 尚無正式登入、多人權限、雲端備份、AI API 串接、故事生成、角色知識隔離或自動故事狀態更新。

## GitHub Pages 部署

- Vite 專案基底路徑設定為 `/AI-Novel/`。
- 部署工作流程：`.github/workflows/deploy.yml`。
- 推送至 `main` 或手動觸發工作流程時，GitHub Actions 會建置並部署 `dist/`。
- GitHub 專案 **Settings → Pages → Build and deployment → Source** 必須選擇 **GitHub Actions**。
- 網址：https://alice2317.github.io/AI-Novel/

GitHub Pages 僅負責靜態前端託管，並不提供 AI 模型服務或後端資料庫。
