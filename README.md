# AI-Novel｜Storyloom

AI 互動小說網頁版前端原型。

## 開發環境
- React 18
- Vite 6
- RWD：桌面優先，支援平板與手機

## 本機啟動
```bash
npm install
npm run dev
```

## 前端功能
- 故事工作台、故事列表、新增與切換故事
- 故事設定編輯：名稱、類型、簡介、原作模式（C-1/C-2/C-3）
- 故事設定與玩家輸入紀錄使用 localStorage 保存
- 故事正文、玩家輸入區、故事資訊側欄
- 原作資料庫、備份與結算入口（尚未實作）
- 桌面、平板、手機 RWD

## 目前限制
目前沒有連接 AI API、雲端資料庫、登入、正式原作資料庫或備份服務。localStorage 資料只保存在目前瀏覽器與裝置；清除網站資料會使其消失。玩家送出訊息後目前只會顯示前端示範回覆，不會呼叫 AI。
